메모리 뚱냥이 (Windows 버전) 🐱
=================================

바탕화면에 떠 있는 작은 고양이. C: 드라이브가 꽉 찰수록
애기냥 -> 돼지냥으로 빵빵해집니다. 우클릭으로 테마/크기 변경.


[ 폴더 구성 ]
  windows_cat.pyw   ... 본체
  frames\           ... 고양이 그림 (테마별 PNG)
  config.json       ... 설정 (자동 생성)
  requirements.txt  ... 필요한 패키지
  build_exe.bat     ... (선택) exe 만들기


────────────────────────────────────────
방법 A. 파이썬으로 실행 (권장)
────────────────────────────────────────
1) 파이썬 설치
   https://www.python.org/downloads/  에서 설치
   ※ 설치 첫 화면에서 "Add Python to PATH" 체크 필수!

2) 필요한 패키지 설치
   - Win + R -> cmd 입력 -> 엔터 (명령 프롬프트)
   - 이 windows 폴더로 이동 후 아래 입력:
       pip install -r requirements.txt

3) 실행
   - windows_cat.pyw 더블클릭
   - (검은 창 없이 고양이만 떠야 정상. 안 뜨면 cmd 에서  pythonw windows_cat.pyw  실행)


────────────────────────────────────────
켤 때 자동 실행되게 하기 (선택)
────────────────────────────────────────
1) windows_cat.pyw 우클릭 -> "바로 가기 만들기"
2) Win + R -> 입력:  shell:startup  -> 엔터
3) 열린 시작프로그램 폴더에 방금 만든 "바로 가기"를 옮겨 넣기
   -> 다음 부팅부터 자동으로 고양이가 뜸


────────────────────────────────────────
방법 B. exe 로 만들기 (파이썬 없이 더블클릭하고 싶을 때)
────────────────────────────────────────
※ 먼저 아래 [ exe 와 보안 경고 ] 를 꼭 읽어보세요.
   대부분의 사람에게는 방법 A 가 더 편합니다.

1) 파이썬 설치 후:
       pip install -r requirements.txt
       pip install pyinstaller
2) build_exe.bat 더블클릭
   (저장소 루트 등 다른 폴더에서  windows\build_exe.bat  으로 실행해도 됩니다.
    스크립트가 자기 폴더로 먼저 이동한 뒤 빌드합니다.)
3) windows\dist\MemoryCat.exe 가 생김 -> 그거만 있으면 실행됨
   (config.json 은 exe 옆에 생성됩니다)


────────────────────────────────────────
[ exe 와 보안 경고 ] — 먼저 읽어주세요
────────────────────────────────────────
build_exe.bat 이 만드는 MemoryCat.exe 는 **코드 서명(code signing)이 되어 있지
않습니다.** 개인 프로젝트라 서명용 인증서(EV 코드 서명 인증서, 연 수십만 원대)가
없기 때문입니다. 그래서 다음 일이 "정상적으로" 일어납니다.

  1. Windows SmartScreen 경고
     처음 실행하면 "Windows의 PC 보호 / 알 수 없는 게시자" 파란 창이 뜹니다.
     -> [추가 정보] -> [실행] 을 눌러야 실행됩니다.

  2. 백신 오탐(false positive)
     PyInstaller 의 --onefile 방식은 실행 시 자기 자신을 임시 폴더에 풀어놓는데,
     이 동작이 일부 악성코드와 비슷해서 Windows Defender 나 다른 백신이
     "Trojan:Win32/Wacatac" 같은 이름으로 잘못 잡거나 조용히 지워버릴 수
     있습니다. VirusTotal 에 올려도 몇 개 엔진이 빨간 줄을 띄우는 게 보통입니다.

  ⚠️ 그러니 이 점을 분명히 해둡니다.
     - 인터넷에서 받은 **서명 없는 exe 의 보안 경고를 습관적으로 무시하지 마세요.**
       그건 실제로 위험한 습관입니다.
     - 남이 만들어 올린 MemoryCat.exe 를 받아서 실행하지 마세요. 그 파일이
       이 저장소의 코드로 만들어졌는지 확인할 방법이 없습니다.
     - 신뢰가 필요하다면 exe 를 쓰지 말고 **방법 A(파이썬으로 직접 실행)** 를
       쓰세요. windows_cat.pyw 는 사람이 읽을 수 있는 300줄 미만의 파이썬 파일이고,
       직접 읽어보고 실행할 수 있습니다. 서명 없는 바이너리를 믿는 것보다
       소스를 읽는 쪽이 훨씬 낫습니다.
     - exe 는 "내가 내 컴퓨터에서, 내가 직접 빌드해서 쓰는 용도"로만 권합니다.

  참고: 이 Windows 버전은 네트워크에 아무것도 보내지 않습니다.
        디스크/램 수치는 전부 로컬에서 측정해 화면에만 그립니다.


[ 사용법 ]
  - 고양이 드래그   : 위치 이동
  - 고양이 우클릭   : 디스크/램 상세 + 테마 + 크기 + 종료
  - 테마 4종        : 귀여운 / 단순한 / 광기 / 경각심
  - 크기 4종        : 작게 / 보통 / 크게 / 왕
  - 언어            : 한국어 / English (시스템 언어를 따라가고, 메뉴에서 바꿀 수 있습니다)
