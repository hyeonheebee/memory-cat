메모리 뚱냥이 (Windows 버전) 🐱
=================================

바탕화면에 떠 있는 작은 고양이. 시스템 드라이브(보통 C:)가 꽉 찰수록
애기냥 -> 돼지냥으로 빵빵해집니다. 우클릭으로 테마/크기 변경.


[ 폴더 구성 ]
  windows_cat.pyw   ... 본체
  frames\           ... 고양이 그림 (테마별 PNG, 기본 제공분)
  requirements.txt  ... 필요한 패키지
  build_exe.bat     ... (선택) exe 만들기

  설정(config.json)·API 키(.env)·직접 만든 테마는 이 폴더가 아니라
  %APPDATA%\Memory Cat\ 에 자동 생성됩니다 (exe 를 다른 위치로 옮겨도
  안 사라집니다).


────────────────────────────────────────
방법 A. 파이썬으로 실행 (권장)
────────────────────────────────────────
1) 파이썬 설치
   https://www.python.org/downloads/  에서 설치
   ※ 설치 첫 화면에서 "Add Python to PATH" 체크 필수!

2) 필요한 패키지 설치
   - Win + R -> cmd 입력 -> 엔터 (명령 프롬프트)
   - 이 windows 폴더로 이동 후 아래 입력:
       pip install -r requirements.txt

3) 실행
   - windows_cat.pyw 더블클릭
   - (검은 창 없이 고양이만 떠야 정상. 안 뜨면 cmd 에서  pythonw windows_cat.pyw  실행)


────────────────────────────────────────
켤 때 자동 실행되게 하기 (선택)
────────────────────────────────────────
고양이 우클릭 -> "윈도우 켤 때 같이 실행" 체크
   -> 다음 부팅부터 자동으로 고양이가 뜸 (다시 누르면 꺼짐)
   - 관리자 권한은 필요 없습니다 (현재 사용자 시작 프로그램에 한 줄 등록)
   - exe 를 다른 폴더로 옮겼다면 옮긴 exe 를 한 번 실행하면 경로가 고쳐집니다
   - exe 를 지우기 전에 체크를 먼저 꺼 주세요


────────────────────────────────────────
방법 B. exe 로 만들기 (파이썬 없이 더블클릭하고 싶을 때)
────────────────────────────────────────
※ 먼저 아래 [ exe 와 보안 경고 ] 를 꼭 읽어보세요.
   대부분의 사람에게는 방법 A 가 더 편합니다.

1) 파이썬 설치 후:
       pip install -r requirements.txt
       pip install pyinstaller
2) build_exe.bat 더블클릭

   터미널에서 돌린다면 쓰는 터미널에 따라 다릅니다.
       명령 프롬프트(cmd)  :  build_exe.bat
       PowerShell          :  .\build_exe.bat      <- 앞의 .\ 를 빼면 안 됩니다
   PowerShell 은 보안상 현재 폴더의 명령을 자동으로 찾지 않아서,
   .\ 없이 치면 "용어가 인식되지 않습니다" 오류가 납니다.

   (저장소 루트 등 다른 폴더에서  windows\build_exe.bat  으로 실행해도 됩니다.
    스크립트가 자기 폴더로 먼저 이동한 뒤 빌드합니다.)
3) windows\dist\MemoryCat.exe 가 생김 -> 그거만 있으면 실행됨
   (config.json 은 %APPDATA%\Memory Cat\config.json 에 생성됩니다 —
    .env·frames 와 같은 자리입니다)


────────────────────────────────────────
[ exe 와 보안 경고 ] — 먼저 읽어주세요
────────────────────────────────────────
build_exe.bat 이 만드는 MemoryCat.exe 는 **코드 서명(code signing)이 되어 있지
않습니다.** 개인 프로젝트라 서명용 인증서(EV 코드 서명 인증서, 연 수십만 원대)가
없기 때문입니다. 그래서 다음 일이 "정상적으로" 일어납니다.

  1. Windows SmartScreen 경고
     처음 실행하면 "Windows의 PC 보호 / 알 수 없는 게시자" 파란 창이 뜹니다.
     -> [추가 정보] -> [실행] 을 눌러야 실행됩니다.

  2. 백신 오탐(false positive)
     PyInstaller 의 --onefile 방식은 실행 시 자기 자신을 임시 폴더에 풀어놓는데,
     이 동작이 일부 악성코드와 비슷해서 Windows Defender 나 다른 백신이
     "Trojan:Win32/Wacatac" 같은 이름으로 잘못 잡거나 조용히 지워버릴 수
     있습니다. VirusTotal 에 올려도 몇 개 엔진이 빨간 줄을 띄우는 게 보통입니다.

  ⚠️ 그러니 이 점을 분명히 해둡니다.
     - 인터넷에서 받은 **서명 없는 exe 의 보안 경고를 습관적으로 무시하지 마세요.**
       그건 실제로 위험한 습관입니다.
     - 남이 만들어 올린 MemoryCat.exe 를 받아서 실행하지 마세요. 그 파일이
       이 저장소의 코드로 만들어졌는지 확인할 방법이 없습니다.
     - 신뢰가 필요하다면 exe 를 쓰지 말고 **방법 A(파이썬으로 직접 실행)** 를
       쓰세요. windows_cat.pyw 는 사람이 읽을 수 있는 파이썬 파일 하나이고,
       직접 읽어보고 실행할 수 있습니다. 서명 없는 바이너리를 믿는 것보다
       소스를 읽는 쪽이 훨씬 낫습니다.
     - exe 는 "내가 내 컴퓨터에서, 내가 직접 빌드해서 쓰는 용도"로만 권합니다.

  참고: API 키를 넣지 않으면 이 Windows 버전은 네트워크에 아무것도 보내지
        않습니다. 디스크/램 수치는 전부 로컬에서 측정해 화면에만 그립니다.
        AI 기능(선택 사항)은 아래 [ AI 기능 ] 항목을 참고하세요.


[ 사용법 ]
  - 고양이 드래그   : 위치 이동
  - 고양이 우클릭   : 디스크/램 상세 + 테마 + 크기 + 종료
  - 테마 4종        : 귀여운 / 단순한 / 광기 / 경각심
  - 크기 4종        : 작게 / 보통 / 크게 / 왕
  - 무엇으로 뚱뚱해질까 : 메모리(기본) / 저장공간 / 둘 중 배부른 쪽
                     (고양이 그림과 "상태" 이름이 같은 지점에서 함께 바뀝니다)
  - 언어            : 한국어 / English (시스템 언어를 따라가고, 메뉴에서 바꿀 수 있습니다)
  - 이름 지어주기    : 우클릭 -> 이름 지어주기… (진단 결과 첫 줄에 그 이름으로 불러요. 비우면 뚱냥이)


────────────────────────────────────────
[ AI 기능 (선택, 본인 API 키 필요) ]
────────────────────────────────────────
고양이 우클릭 메뉴에 두 항목이 있습니다.
  - 🐾 뭘 먹은 거야?          : 왜 용량이 찼는지 설명만 해 줍니다 (파일을
                                지우거나 옮기지 않습니다)
  - 내 반려동물로 테마 만들기… : 사진 한 장으로 나만의 테마를 만듭니다

둘 다 선택 사항이고, 본인의 OpenAI API 키가 있어야 동작합니다. 키가 없으면
두 메뉴 모두 "API 키가 필요해요" 안내만 뜨고, 네트워크에는 아무것도 보내지
않습니다.

1) 키 넣는 법
   - Win + R -> cmd 입력 -> 엔터 (명령 프롬프트)
   - 아래 두 줄을 각각 입력 (첫 줄에서 "이미 있습니다" 오류가 나도
     괜찮습니다)
       mkdir "%APPDATA%\Memory Cat"
       notepad "%APPDATA%\Memory Cat\.env"
   - 새 파일을 만들지 물으면 "예"
   - 아래 한 줄을 따옴표 없이 붙여 넣고 저장 (Ctrl+S)
       OPENAI_API_KEY=sk-...
   - 저장할 때 인코딩은 "UTF-8" 그대로 두기 (메모장 오른쪽 아래에 표시)
   - 저장할 때 파일 이름이 ".env.txt" 가 되지 않았는지 확인
   - 고양이 우클릭 -> 종료 후 다시 실행

2) 사진 테마 만들 때
   - PNG / JPG / JPEG / WebP 파일만 됩니다 (HEIC 는 안 됩니다 — 아이폰
     사진은 먼저 JPEG 로 바꿔서 올려주세요)
   - "OpenAI로 사진을 보낸다"는 동의 창이 뜨고, 눌러야 업로드됩니다

3) 진단(🐾 뭘 먹은 거야?)은 설명만 합니다. 파일을 지우거나 휴지통으로
   옮기지 않습니다. (성격 기능과 안전한 용량 정리 자동화는 아직 macOS
   버전에만 있습니다.)

4) exe 로 실행했는데 이 메뉴 두 개가 아예 안 보이면, AI 모듈을 불러오지
   못한 것입니다. %APPDATA%\Memory Cat\Logs\ai-features-unavailable.log
   에 오류가 남아 있습니다.
